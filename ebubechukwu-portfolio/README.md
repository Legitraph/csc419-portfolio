## Run locally
1. Install Node.js (LTS).
2. Open this project folder in a terminal.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open the local URL printed by Vite.

## Build for production
```bash
npm run build
npm run preview
```

The production-ready site is generated in the `dist/` folder.

## Deploy on Vercel
1. Push this project to a GitHub repository.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the repository.
4. Keep the detected Vite settings:
   - Build command: `npm run build`
   - Output directory: `dist`
5. Deploy and copy the live URL into your assignment submission.

## Push to GitHub
Create an empty repository on GitHub named `csc419-portfolio`, then run these commands from this folder:

```bash
git init
git add .
git commit -m "Build CSC 419 personal portfolio"
git branch -M main
git remote add origin https://github.com/Legitraph/csc419-portfolio.git
git push -u origin main
```

If you choose a different repository name, replace `csc419-portfolio` in the remote URL.
